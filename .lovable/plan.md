# Owl View logo — clean recreation from the uploaded card

## Goal
Recreate the photographed Owlview logo as a sharp, clean digital logo, then adopt it across the website in place of the temporary "O" circle mark.

## What gets made

1. **Two color versions of the same clean recreation** (so you can compare side by side):
   - **Blue + gold** — faithful to the uploaded card: deep royal blue mark and lettering, warm gold accents.
   - **Website palette** — the site's aubergine plum + champagne gold.
2. **The mark itself**, redrawn cleanly from the photo:
   - House/roof outline forming the owl's head and brows, with the small roof-notch triangle at the top right.
   - Two large round eyes with gold ringed pupils.
   - Small gold diamond/leaf accents (the one above the eyes and the one below the face).
   - The name "Owl View" as the only text — no RC number, no phone number in the logo itself.
   - Produced with the premium image generator on a transparent background, logo centered with margins.
3. **Inspection pass**: each candidate checked for correct lettering, crisp shapes and readability at header size (small) and on light and dark surfaces; defects fixed by editing the candidate directly. Files saved under `ads/creatives/` with the name and "logo" in the filename.

## Your choice
- Both versions are shown to you in a pick-one question; you choose which becomes the official logo. The unchosen file stays on disk for reference.

## Adoption into the website (after your pick)
1. The chosen logo file is copied into the project and shown in the **header** and **footer**, replacing the current circle-with-"O" placeholder next to the brand name.
2. A square favicon is derived from the same file and set site-wide.
3. The registration number in the site config is corrected to **RC: 1849993** (you confirmed the card is right; the footer currently shows 2580011).
4. Verification: build check plus a browser screenshot of the header, footer and favicon to confirm the logo reads well on the ivory background and at small size.

## Notes
- A logo image is a picture, not an editable vector file — if you ever need print-grade vector artwork, that would be a separate redraw step.
- The photographed original stays untouched; nothing overwrites it.
